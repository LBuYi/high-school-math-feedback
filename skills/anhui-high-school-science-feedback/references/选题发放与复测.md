# 选题、发放与复测

## 从原答到题源候选

同步训练先看本校本届实际用书与进度，再找合肥同阶段可核读的校卷或教研题。按年级、学期、章、题型与目标动作匹配，记录学校、原卷名称及日期。合肥模考和安徽高考相关卷分别记来源。

把学生的可见步骤和下一题要写的证据连起来。例如“水平合力列式漏掉摩擦力 → 检查在物块滑动方向改变后，能否定出摩擦力方向并列出合力”。先确定练习或复测的用途，再选题。

| 核对项 | 通过条件 |
| --- | --- |
| 完整题面 | 题干、所求、选项、条件、数据、坐标单位、图例及相关小问读全。物理电路和力的方向、化学流程箭头与装置接口、生物图例与对照组尤其需要查清。缺关键图时留候选，原解析不可见时可完整独立解题并如实记载。 |
| 目标与范围 | 先从原答定一个可观察的动作，能指出练习中哪一步需要同一判断，并核对相关方法已经学过。只有选项时，先用能区分原因的短题或补写依据，错因留待核对。 |
| 新增负担 | 把要诊断的一步和额外的运算、仪器、结构图、实验机制或阅读负担分开。同步练习优先挑低负担题，需要才加入综合题。 |
| 判定依据 | 先写出教师要看到的式子、图、条件或解释。答对但关键步骤看不到时，仍需补依据。遇到另一种有效解法，按它是否提供同一目标的证据判断。 |
| 独立核验 | 从完整题面重做，逐项核对分支、假设、状态、边界、数据和所有可接受答案。改动一项条件后重验整题，检查题图与解析一并更新。 |

新增练习、独立复测或实质改题时，沿用数学版成熟的核题方式。只改文字、版面或打包时沿用本批已核读的来源。

1. 先按“学科、年级或册次、目标动作、关键条件”查[本地题库](本地题库维护.md)。需补新题时用浏览器打开[组卷网](https://zujuan.xkw.com/)到题目详情，数学、物理按[题型参考与配图](paper-reference-and-figures.md)核对实际设问和用图。同步题优先找本校与合肥同进度，候选不足时扩大地区。检索词只含题目特征。
2. 打开候选详情，逐项按上表核对条件、所求、必要图和单位。搜索摘要、知识点栏和不完整题图只能作为检索线索。题面完整且原解析未开放时，可自行解题，并注明核读范围。按“可直接用、改编、方法参考、排除、待核读”记录实际用途和理由。
3. 在教师记录写实际检索词、查阅日期、候选链接或题号、原卷出处、核读范围、适配理由、改动和独立验题结果。用到历史来源时区分当时核读日期与本轮访问结果。按真实关系标原题、具体改编、方法参考后自编或自编。可在交付正文简短说明本次实际采用了哪一类来源。
4. 页面受限时可查同进度校卷、[菁优网](https://www.jyeoo.com/math2/report)或[二一组卷](https://zujuan.21cnjy.com/)的公开详情。各题、图表、解析及下载按实际能读到的范围分别记录。有完整的现场题卷、PDF 或截图时可从材料核读。题源不足时，用已核题变式或自编并独立验题。用户限定只用指定平台新题时，留实缺并先完成其余可做部分。

## 梯度与完成标准

独立验题只说明题目可以正确作答。对症、可见证据、难度功能三项再按[考查价值审核](hefei-feedback-sop.md)检查。

- **基础**保留原来的关键结构，换数或换呈现，练清楚原来遗漏的动作。已能独立写出这一步时，题量可以减少。
- **巩固**改变一个会影响判断的条件，观察孩子能否在新条件下重新判断。例如最值点由区间外变到区间内，物块相对滑动方向改变，反应物用量关系变化，实验材料的对照关系改变。
- **提高**在同一目标已较稳定、前置方法已学的情况下加入迁移或综合。题量按要补的动作和作答负荷决定。少量需要自行选法或调动已学内容的综合题可放同卷卷尾，不作为独立复测。
- **复测**按请求另选未布置、未看过答案的题。教师先定关键步骤，再分别记结果、步骤与独立性。给两道等价题时也要看学生是否说清依据。

每组至少有一问能看到学生自己的判断。基础可以减轻运算，要求写清某一步的依据。巩固改变一个会改变判断的条件，提高才在已学范围内增加边界分类、逆推、证据评价或迁移。换题型、增加阅读量和运算量时，仍要说明新增的是哪一步判断。选好后尝试用最短的正确方法解题，看题面是否已把判断交代完，或是否有特例、前问答案和选项结构让学生绕过训练目标。能用其他方法讲清同一依据时照常接受。

| 学科 | 可以怎样设问 | 应看到的判断 |
| --- | --- | --- |
| 数学 | 错解辨析、图象判断、分问求值、反求参数 | 最值点能否取到，边界是否纳入，以及存在和恰有一个分别怎样成立。 |
| 物理 | 补画受力图、读图象、换运动方向后列式 | 研究对象、相对运动与力的方向，条件变化后合力如何变。 |
| 化学 | 方程式辨析、计量对照、装置和流程小问 | 物种或反应条件的限制，变投料比后按谁计算，是否需要重新判断。 |
| 生物学 | 图表取证、补实验对照、评价结论 | 选哪两组及什么指标，控制了哪些因素，数据能支持到哪一步。 |

例如二次函数配方正确但取错了最值点，基础查能否先选点，巩固让顶点恰在端点或改变不等号。提高可用已学的简单方程求根，再按闭区间筛选，判断恰有一个解的参数范围。设问写明开闭区间，解析检查根恰落在端点时的结论。只有答题卡上的选项时，优先让学生补写判据，再用变化条件检验。

数学训练能沿同一条件自然推进时，按[递进小问](math-progressive-questions.md)先定末问，再设计基础判断和中间变化。每轮有已学范围内的参数、证明或综合迁移目标且适合分问，至少选一道 2—3 问。逐问记录新加的判断，核对终问的条件和边界。

## 编册与语言

- 已核原错题独立排成重做题，保留题号、必要图表和空白。原题旁或后面只补简短易错提醒，不印学生原答、错选项、批改、标准答案或逐步提示。原错题后紧跟对应配练。训练只用中性标题，知识点与分点的解题技巧写在解析册，每组末总结技巧。局部可读时只收条件完整的小问，原题整段缺失时可先出独立练习。
- 解析按原卷分册，与训练共用题面并对齐条件、所求、单位、指标和图表。逐问写规范作答。原卷有两种可能读法时，保留已确认的部分，待核小问和两种读法留给教师。依据原卷或清楚图件补核后再作学生材料。
- 复测用新题，题面保留必要数据或图和作答要求，移去训练页要点及方法提示。改变会影响判断的条件、模型、图表呈现或对照关系。若一个便捷算法只拿到结果，补“说明理由”即可。看过答案后订正与独立新题分别登记。
- 学生训练、解析及按需制作的复测和教师答案默认出 PDF，按[统一排版](输出内容与排版规范.md)制作并[核对成品](PDF制作与核对.md)。
- 训练和复测用留白分开不同题目，作答区默认用整块空白，大小按预计作答量确定。数学给连续的推导区，物理同时要求画图与列式时可并排留空并用小字标注，化学按方程式及所需说明留空，生物学按要写出的实验条件、依据与结论留空。需要填写的具体位置、图表和坐标按题目保留。逐页核对留白是否够写、是否能看出各题作答区的归属。
- 学生解析的原题步骤可编号，较长公式和离子方程式单独成行。内容较长时在完整题组或自然步骤处分开。
- 共用材料尽量只写一次。多问逐问另起一行，整题按预计总书写量统一留白。设问之间有意递进时核对能否看出每问的判断。细化作答格式见[学生解析答题规范](学生解析答题规范.md)。

## 发放前核对对应版本

四科原题重做、训练、复测都按[发放前逐题验收](item-release-review.md)查题意、答案、图和完整作答。训练和复测有化学概念判断时，再按[化学概念题验收](化学概念题验收.md)核教材依据、正误设问及选项顺序。待核的题先退出可发放版。

生成后的文档先放候选位置，以[批次核对单](../assets/批次核对单.md)或等效记录检查。核实实际题源、核读范围、深度和版本，确认训练题面不堆提示，解析每组有必要知识点、逐问规范作答和分点的解题技巧。逐问对照两册题面与解答，再核家长稿及 PDF 页图。确认后记有效文件，并按[本地题库维护](本地题库维护.md)登记本轮可复用题及题号。改题面、图、字体或排版时重看受影响页。家长稿修改后重出对应 TXT 与 PDF。未受影响的学生材料可引用已核对的文件摘要。

个别发放按内部编号查本人的已核材料，重新读清单指定文件，核对人、文件角色和摘要。多人整包是教师备课材料。依据实际约定发放相应角色，首次可只给训练。用既有数学工具生成时，应从候选清单走同样的核对，再维护有效清单。工具中的同名报错要回到内部编号选择本人材料。

## 收回后按实际布置回填

让学生合上解析重做原题，看原来漏掉的判断或步骤能否独立写出来。再看同组变式改条件后会不会重新判断。分别记录原题重做、变式表现和独立复测。不只看结论，绕过目标的正确结果不能代替相应证据。

| 来件 | 怎样处理 |
| --- | --- |
| 某人某题补交 | 先定位学生、已布置版本与题号。补页关联同一次作答，重做另记一次。只处理这份新增证据及对应目标。 |
| V1 已布置，V2 已生成或也已布置 | 按学生实际做的卷记入其发放条目。V1 只交第一题就在 V1 核对第一题，余题按 V1 的约定和原状态记录。未发的 V2 无待交项。 |
| 版本相符但无布置记录 | 保留收到的原件和学生说明，核对是否确有发放或自练。能辨认题面时可单独记为自练或待确认的作答。 |
| 只交答案或有过帮助 | 分开记录结果、关键步骤和独立性依据。答案对但过程缺失，补问相应依据。有提示时按所见证据记录，另换新题再观察独立表现。 |

收到与核对是两个时间点。可以记关键步骤独立通过、达到本轮要求或仍待巩固。未交题暂不判断学习表现。教学侧按实际复测与后续作答决定是否继续练，归档保留原始批改及相同目标的多次记录。月度按实际作答日期汇总，只收错题时不换算整卷错误率。
