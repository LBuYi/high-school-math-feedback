# 本地题库维护

每次配练都筛出值得复用的题，并在成品核验后回填课程项目的 `本地题库`。先找项目已有的题库位置。新项目需要时，在当前课程工作区建 `本地题库`，按实际已有题目的科目建子目录。一题一档，UTF-8 Markdown 可直接查看，`索引.md` 按学科、章节、目标和题型链接题档。随工作区使用绝对路径不同时，以项目中的相对位置找到题库。

## 挑选、入库、再用

1. **先查再选。** 用“学科＋年级或册次＋要写出的关键判断”查本地题库。核对学过的方法、完整题面和已有使用记录。外部新题或待补题源按[选题标准](选题发放与复测.md)检索。已经核过且对准目标的离线题可直接进入本轮验题。
2. **本轮验收后入库。** 题面和图表在本地齐全，出处或创作关系清楚，可以独立解出全部小问，有清楚的目标、关键证据和可用的标准解答，才纳入可复用题。附图用与题档同行的本地文件，通过相对路径打开，逐项检查符号、单位和图例。深度体现在如何判断、比较、排除或迁移。基础题也可入库，需说明它能有效检查哪一步。只收录长题中可独立使用的小问时，保留它用到的共同前提，并写清原卷小问号。
3. **保留出处与可读范围。** 原先可核读但无法留全题面或无法在本地完整复做的题，放在索引的“题源线索”，记录链接、原卷或网站标注、题号、核读日期与范围。可自行设计完整变式入库，写明与原题的关系。用到本校卷或用户提供的材料，按实际留存材料定位和使用范围。
4. **去重和修订。** 同题多出处在同一题档补来源。只改数字且判断路径相同，优先在同一题档记变化用法。改变关键条件、目标或答案的变式另设题号并标母题。勘误保留原题号和旧版定位，记录证据和修订日期。旧版已经布置时，批次记录继续指向实际布置的版本。
5. **回填使用。** 本轮选用的题在批次核对单写题库 ID、版本和用途。本地题档可以补样例或批次编号、观察到的难点及改进，真实布置和学生作答继续按学生批次档案登记。复测查学生实际做过、看过的卷与解析，也查母题关系，避免用换数即同法的近重复题冒充新证据。

## 一题一档至少保留什么

化学概念题一并留存[逐项核验记录](化学概念题验收.md)或可回查的记录位置。同版复用核对成品，改变题意重新验证。教师反馈有误的对应版本先标待核，重验通过后恢复复用。

| 部分 | 内容 |
| --- | --- |
| 基本定位 | 稳定题号、版本、学科、年级或模块、章节、题型、适用层次和前置方法。教材版别只按实际核对记录。 |
| 题目与解答 | 完整题面、必要图表、逐问规范解答、容易误判的条件及边界。一题多问逐问给判据。 |
| 复用条件 | 适合补哪一步、怎样看出学生真正做到了、思维深度在哪里。注明适合练习还是也可用于条件不同的复测。 |
| 来源与核验 | 原题、具体改编、方法参考后自编或自编，附出处或材料定位、核读范围、核验日期和变化关系。原解析读不到时可记独立解答的结果。 |
| 使用记录 | 试排或实际批次据实填写，回收后可补发现的歧义及题目调整。学生姓名、答题卡和个人反馈留在学生档案。 |

复用时以题档与实际核验为据。发现题面有误或图表缺失，先标待核，暂停使用相关版本，纠正后再重新验题。只要求文字反馈的批次沿用原交付范围。
