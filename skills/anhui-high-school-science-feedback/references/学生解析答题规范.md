# 学生解析答题规范

学生解析兼有订正讲解和答题示范。每组重列完整原错题、必要图表及可辨认的原答，先把知识点及其适用条件、首次可以确认的错处分点说清。原答不全时标出能确认的部分。讲解后单列“原题解答”。同类练习按训练册题号和小问对应，复用题面和图表。

## 怎样写规范解答

1. 主观题以“解”或“证明”起笔。多问题逐问作答，编号与卷面一致。先写所用的已知条件、对象、关系或定理，再推导。使用前问结果时交代引用处。
2. 把会影响结论的步骤写全，使用“由”“因为”“所以”“综上”等把依据和结果接起来。等式、推出和等价关系按真实逻辑书写。计算较长或需要对照时，把关键式独立成行。各分支先写适用条件，再推到结论，最后合并。必要时回代、取舍，查等号、端点、单位、方向和适用范围。
3. 结尾直接回答所问。证明题回到待证结论，选择和填空的解析也写出关键依据。结果相同的等价做法按依据核对。解析示范选用学生学过、能完整解释条件的一种方法。
4. 全组结束后用简短分点写“方法回顾”。每点给能搬到下一道题的判断或自查动作。技巧与原答讲解留在这些栏内，标准解答可独立作为答题示范。

| 学科 | 解答时着重核对 |
| --- | --- |
| 数学 | 写清定义或条件、使用的性质和所求范围。最值写取得点及其依据。涉及方程、不等式、参数时，核对可逆性、分类的分界和合并后的解集。存在性写清能否取到，恰有一个还要核对排除其他解。 |
| 物理 | 交代研究对象、过程及参考方向，必要时画图。先写带符号的物理关系，交代适用条件，再代入数据。按题意交付单位、方向和含义，图与式中的方向相符。 |
| 化学 | 写清题设条件与物种形态。方程式按要求配平并核对质量和电荷守恒，注明必要反应条件。定量题交代限量反应物和计量依据，结论带所需单位。 |
| 生物学 | 数据或实验题点明比较组别、指标和足以支持结论的差异。按所问回答机制、推论或对照设计。结论限于实验条件及证据能支持的范围。 |

## 出 PDF 前逐问验收

- 条件、图表和编号逐项与训练对齐。每一问的答案、边界、单位或图均可独立核对。
- 用笔复算或独立推理，读者可从已知条件沿推导到结论。把可能漏掉的分支、端点、有效解、对照或实验限制拿出来核一遍。
- 一段订正讲解和一份完整作答各有自己的位置。把原答、知识点或方法回顾暂时遮住，标准解答仍然完整可读。
- 生成后按[纸面核对](PDF制作与核对.md)逐页读实际 PDF，检查分问、公式、图及分页。
