# 学生解析答题规范

学生解析按卷单独制作。重列可确认的原题及必要图表，用“知识点”说明依据，再单列“原题解答”。同类练习与训练共用题面和题号。学生原答、错因和批改留教师记录。原题及必要图表不全时，完整的同卷练习可先给解答。

“原题解答”是学生重做后可对照的标准作答，不是展示该生当时怎么答。不得以编号、选项或得数表替代。解析按[四科逐题验收](item-release-review.md)检查，遮住结论仍能顺着条件、依据和关键推导读通。

## 怎样写规范解答

1. 主观题以“解”或“证明”起笔。多问题一问一块，编号与卷面一致并单列。先写所用的已知条件、对象、关系或定理，再另行写关键推导。使用前问结果时交代引用处。
2. 把会影响结论的步骤写全，使用“由”“因为”“所以”“综上”等把依据和结果接起来。等式、推出和等价关系按真实逻辑书写。计算较长或需要对照时，把关键式独立成行。各分支先写适用条件，再推到结论，最后合并。必要时回代、取舍，查等号、端点、单位、方向和适用范围。
3. 结尾直接回答所问。证明题回到待证结论，选择和填空的解析也写出关键依据。结果相同的等价做法按依据核对。解析示范选用学生学过、能完整解释条件的一种方法。
4. 全组结束后设“解题技巧”，提炼一两条可迁移的方法。分点写什么时候适用、先做什么、怎样检查。写清边界，不重复推导，不把口诀代替依据。标准作答能独立读通。

遇到图上关系或过程容易漏掉时，按[解析配图与图上取证](solution-visuals.md)补函数图象、运动图象、反应流程或实验对照图。图放在用到它的步骤旁边，正文交代怎样由图得出并核实该步结论。图不能替代公式、必要依据或化学方程式。

| 学科 | 解答时着重核对 |
| --- | --- |
| 数学 | 写清定义或条件、使用的性质和所求范围。最值写取得点及其依据。涉及方程、不等式、参数时，核对可逆性、分类的分界和合并后的解集。存在性写清能否取到，恰有一个还要核对排除其他解。 |
| 物理 | 交代研究对象、过程及参考方向，必要时给受力或过程图。先说明适用条件、写带符号的规律，再代入数据。换阶段时写明分界依据，例如“达到同速前后”，核对符号、单位、方向和题图一致。 |
| 化学 | 概念判断中，成立项写依据和适用条件，错误项写明违反的依据或给出反例。选择题核对设问正误及应选项。方程式按要求配平并核对质量和电荷守恒，注明必要反应条件。定量题交代限量反应物和计量依据，结论带所需单位。概念题成品按[化学概念题验收](化学概念题验收.md)核对。 |
| 生物学 | 数据或实验题点明比较组别、指标和足以支持结论的差异。按所问回答机制、推论或对照设计。结论限于实验条件及证据能支持的范围。 |

## 出 PDF 前逐问验收

- 条件、图表和编号逐项与训练对齐。每一问的答案、边界、单位或图均可独立核对。
- 用笔复算或独立推理，读者可从已知条件沿推导到结论。把可能漏掉的分支、端点、有效解、对照或实验限制拿出来核一遍。
- 校验解答缩小或扩大了哪个区间、哪些端点应取舍。共同定义域与解集分别写。盖住知识点或解题技巧后，标准解答依然完整。
- 生成后按[纸面核对](PDF制作与核对.md)逐页读实际 PDF。确认各问、各阶段可分辨，关键式对齐分行，小问编号和开头的推导未分到两页。
