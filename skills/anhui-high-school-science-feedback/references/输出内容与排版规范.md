# 输出内容与排版规范

在合肥高中数理化生错题反馈中按本规范交付。学生、批次、科目与交付范围按本轮已确认的信息填写。

| 材料 | 文件格式 | 必备内容 |
| --- | --- | --- |
| 家长反馈 | 回复正文、UTF-8 TXT、PDF | 同一份老师口吻的稿件。由可核对的题号和作答讲起，写做到的一步、影响结果的一处和一个能动笔的动作。多科按学科写自然段。PDF 加“家长反馈”标题与已确认的学生或批次信息，三份正文一致。 |
| 学生针对训练 | PDF，需配练时交 | 每组依次放完整原错题及可核对的原答摘录、知识梳理、方法小结、同类练习。知识梳理写核心概念、规律、公式与使用条件。方法小结写通用的判断顺序和一个自查点。练习区保留题面、必要图表、基础／巩固／提高标签与书写留白。 |
| 学生解析 | PDF，随训练成对制作 | 原错题和每道练习各有对应解答，按题号写知识点与错处、原题解答、同类练习解析和方法回顾。以“解”或“证明”起笔，写明依据、推导、适用条件及结论。需要判断区间、分类、单位、方向或实验边界时在相应步骤交代清楚。 |
| 独立复测 | PDF，按本轮要求制作 | 尚未做过的新题、必要图表及作答区。用同一目标检查独立完成情况。 |
| 教师答案、题源与验收记录 | 按本轮要求给老师 | 题源与核读范围、原答依据、训练目标、题目适配理由、独立验题结果和复测判据。 |

只要求反馈时交家长稿三种形式。同步配练时教师先看确切题号与作答依据，再交对应训练和解析。学生两册按学科同序合订，共用题面及题号。若按学科布置，沿用同一对应关系。

## 纸型与字体

| 对象 | 默认印刷规范 |
| --- | --- |
| 版心 | A4 纵向单栏。上 24 mm、下 20 mm、左右各 20 mm。黑白打印可辨。 |
| 中文正文 | 家长稿、题干、解析均用思源宋体常规字重（Noto Serif CJK SC）12 pt。按环境选用宋体或 Fandol 宋体作为等效替代。 |
| 标题与栏目 | 中文用微软雅黑粗体，等效替代可用黑体或思源黑体。主标题 18 pt、学科或专题标题 14 pt、栏目标题 12 pt，左齐，深蓝灰 `#243D4C`。题号 12 pt 加重。 |
| 英文和数字 | 正文的英文和数字用 Times New Roman，可用 TeX Gyre Termes。数学变量、数字与符号统一使用数学字体。 |
| 公式 | Cambria Math，可用 TeX Gyre Termes Math 或 Latin Modern Math。变量斜体，函数名与单位正体，分式、上下标按学科规范排印。 |
| 行距 | 正文基线 18 pt，段间距 4 pt，首行不缩进。独立公式上下约 6 pt，长式按相同关系符号对齐。 |
| 页眉页脚 | 宋体 10.5 pt，页眉细线 0.4 pt，页脚居中页码。左页眉“理学优课高中部”。学生训练和解析的右页眉为“针对补充训练”，家长 PDF 的右页眉为“家长反馈”。 |

练习留白深度按实际要写的步骤调整。短判断可从 20—35 mm 起，常规解答可从 45—70 mm 起，综合题及长推导按书写量放宽。物理需要作图时预留画图和运算区域。题干与作答区尽量留在同一页，长解析在完整小问或推导段之间分页。图表和坐标按题目保留。

选题前按[选题与复测标准](选题发放与复测.md)确认可观察的目标动作。家长稿按[文字反馈写法](文字反馈与多科交付.md)根据原答和实交训练写。出文件后按[PDF 制作与核对](PDF制作与核对.md)核对正文同稿、实际嵌入字体、题面、公式、版面和留白。替换字体后记录实际字体，并重新目检。
