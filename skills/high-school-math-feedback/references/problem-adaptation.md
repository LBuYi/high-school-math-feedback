# 常见命名、难度与训练要点

## 函数与辅助式的命名

新编高中训练优先用小写 \(f(x),g(x),h(x)\)。一题已有 \(f\) 时，辅助函数用 \(g\) 或 \(h\)，不要把原函数覆盖。参数在题干明确；通常不必另写 \(R_a,K_a,q_a\) 等函数族记号。

原题和学生原答按原件保留，不能为统一名称而改写历史证据。确需给改编题换名时，题干、解答、图中标注及答案同步更新。实数集 \(\mathbb R\)、判别式 \(\Delta\)、随机变量、事件和数列下标按各自意义使用，不能因字母相同就批量替换。

## 学生页怎么呈现

每组按“完整原错题 → 要点 → 同类练习”组织。用简短的一段合写考点、常用方法和适用条件，通常2—4句，段首可加粗“要点”。说明为什么可以用某种方法。新题的题面保留必要条件和所求，独立复测撤去方法提示。

每道训练题标“基础／巩固／提高”，选做可合成“提高，选做”。不加彩色徽章、星级和成串标签。详细适配理由保留在教师记录，学生页不放“适配度高”等审核语言。

| 层次 | 本轮设计用途 |
| --- | --- |
| 基础 | 先检查一个必要动作，减少无关运算和综合条件 |
| 巩固 | 在同类新题中完整运用方法，并检查条件与边界 |
| 提高 | 增加参数分类、范围变化或综合迁移，须有相应前置知识 |

分层是针对当前目标的设计判断，不是官方难度、预测正确率或对学生能力的评级。实际作答后可调整。题量仍按目标与负荷决定。

## 教师怎样判断适配

逐题记录原题或错误步骤、考点、关键动作、解题通法、前置知识、设计层次、选用理由、题源关系与待观察点。适配理由要回答“这道题能检查原错题中的什么”，不能只写“同类型”或“适合高一”。

按[组卷网筛选顺序](question-research.md#逐题筛选)先查清题面，再写出目标动作在新题中出现的位置。核心巩固题允许正确的不同解法，按活动目标判断是否还需问一行等价变形或条件依据。用于复测时按原目标选择适当变化，检查目标动作依然可观察。

只有最终答案时，用新题观察候选解释，不把未知原因写成已证实。基础方法与提高题分别验收；提高题未完成，不自动否定基础已经改善。题面相似而关键动作不同、前置方法未学或运算掩盖目标的题应调整。

## 要点的数学边界

- 判别式法须先确认所讨论的式子确为二次式；二次项系数为零时单独处理。
- 开口向上、定义在全体实数上的二次式，存在非正值可用判别式非负判断；限制到区间后，需结合对称轴及端点，不能只看判别式。
- 定义域包含0时，奇函数才可直接写 \(f(0)=0\)。把函数值比较转成自变量比较时保留定义域和单调性范围。
- 求最小值既要证明所有取值不低于候选值，也要说明候选值能够取得。半开区间的界不一定能取到。
- 先核对所求是最大值还是最小值，以及二次函数开口方向。对称轴在区间内时，顶点处也不一定给出题目所求的最值；不能把求最小值的步骤直接套给最大值。

以上是方法的适用条件，不是学生已经出现的错误。新增或采用的具体题目仍从实际题面独立核验。
