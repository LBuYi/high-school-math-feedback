# 跨 Agent 运行方式

把 `SKILL.md` 当作唯一入口。支持技能目录的宿主可加载整个目录，支持附件的可直接给它 `SKILL.md`，只能输入文字的可粘贴同一文件正文。多台设备可从同一共享位置取这份文件或完整目录。使用完整包时按需读取模板、样本或执行脚本。

要携带本版的家长口吻、教研摘要、档案规则和诊断示例，分享完整目录而非仅入口文件；不依赖原作者的 `AGENTS.md` 或历史聊天。离线可读取内置摘要，联网和登录由接收方提供。可迁移范围与交付检查见[可迁移内容与质量验收](portability-and-quality.md)。

口语反馈、PDF 核读、题源检索、数学审校和分册规则均在此技能。优先复用当前宿主已有工具，按任务检查能力；只写反馈时不用检测编译器。

| 工作 | 先用现有能力 | 能力缺失时的交付 |
| --- | --- | --- |
| 已核读的材料、教师口吻 | 读文字稿和 [教师口吻样本](teacher-voice.md) | 只有聊天输入也可粘贴原题、原答、批改与待确认点 |
| 有文字层的 PDF | 宿主 PDF 工具或现有 MarkItDown、pypdf | 接收提取文本；公式、图和批改仍按页核对 |
| 手写答题卡、扫描 PDF | 直接看原页，或本地拆页后看图；现有授权 OCR 可辅助 | 接收教师核对的转录，保留疑点；只有图却无法读图时先处理能确认的资料 |
| 组卷网选题 | 浏览器检索或已授权题库接口，核读详情 | 优先用提供或已核读的题，范围允许时自编并标明 |
| 数学核验与绘图 | 独立推导；有 SymPy 时复核适用结论，按需用 TikZ 或 Matplotlib | 提供可核对的推导，按实际情况注明数学图或工具核验的状态 |
| 数学 PDF | 宿主 LaTeX 工具，或 XeLaTeX、ctex、中文字体与渲染工具 | 提供完整 TeX 源码，另给可直接阅读的内容 |

## 可选本地脚本

`python <skill>/scripts/inspect_runtime.py` 只检查当前解释器和搜索路径。现有宿主工具也可以代替脚本。需要运行包内脚本时按实际工作使用 `requirements.txt` 中对应的 Python 依赖。单纯读技能、写反馈、浏览网页时不运行这些命令。

- [手写页核读](handwriting-review.md) 的拆页脚本用 Python 3.11 或更新版、Pillow，处理 PDF 时再用 pypdf 和 Poppler 的 `pdftoppm`。
- [数学核验](math-and-diagrams.md) 的辅助脚本用 SymPy。
- [PDF 制作](pdf-production.md) 与 [打包](retest-and-delivery.md) 的辅助脚本用 pypdf。PDF 编译还需要编译器、中文宏包和字体，目检需要页面渲染。

技能包保存指令、模板和本地脚本。浏览器登录、看图能力、视觉服务和编译环境由当前设备或 Agent 提供。应用用户明确授权的范围；脚本只处理本地输入，不自动配置账户、安装依赖或上传材料。

## 版本与材料

班级、章节、试卷范围、题量和人员来自本批任务。学生材料、课堂记录、题源会话和输出放到具体批次目录。分享技能时只分享通用包，跨设备传阅学生材料按项目已有权限处理。工具是否执行和读到了什么以实际结果为准。
