# 内部模块与运行环境

## 合并方式

本技能将项目 SOP v1.5、执行卡和用户已确认的修订要求整理为一条高中工作流程，并吸收相关技能的操作方法。它不是若干技能文件的原样拼接，也不要求常规任务先安装下表中的全部技能。以下能力已在本包给出操作要求：

| 参考能力 | 本包中的落点 |
| --- | --- |
| math-pretest-feedback：原始证据、身份核对、口语反馈、状态归档 | [材料与反馈](materials-and-feedback.md)、[归档与交付](retest-and-delivery.md) |
| humanizer-zh：保留事实与确定程度、减少套话；用户提供的教师反馈样本 | [教师口吻与样本](teacher-voice.md)，常规反馈直接使用本包规则，不必额外加载完整润色技能 |
| junior-math-handouts：出版审校与题答一致 | [PDF 制作](pdf-production.md)，不继承初中班型、课前测题量或家长反馈规则 |
| markitdown：文档转文本与局限 | [材料与反馈](materials-and-feedback.md) |
| sympy：精确计算、假设、检查报告 | [数学核验](math-and-diagrams.md)、`scripts/math_checks.py` |
| tikz-diagrams：基于数学定义绘图与图文一致 | [数学核验](math-and-diagrams.md) |
| matplotlib：可复现函数图、矢量导出 | [数学核验](math-and-diagrams.md) |
| latex-compile / pdf：运行时检测、编译、渲染与实际目检 | [PDF 制作](pdf-production.md)、`scripts/compile_pdf.py`、`assets/preamble.tex` |
| 浏览器/检索工具：核读组卷网原题和准确留痕 | [组卷网与训练设计](question-research.md)，API 以当前工具文档为准 |

不继承与本项目无关的工作流，如每次只处理一张照片、初中固定题量、强制家长报告或统一答题卡包。本次范围优先，既有用户授权不因技能再要求确认。用户明确调用某个外部技能时仍应读取并遵循其适用要求；特殊文档类型或高级绘图能力也可按需加载，不把技能名称当作已经执行的证据。

## 软件依赖

先运行 `python <skill>/scripts/inspect_runtime.py`，或使用宿主提供的工作区依赖定位工具。检测结果只表示当前解释器/路径中发现的能力；其他已安装运行时可能仍需定位。禁止为了检测导入和执行来源不明的项目脚本。

| 操作 | 依赖 | 缺失时 |
| --- | --- | --- |
| 证据索引 | pypdf；MarkItDown 可选 | 用现有 PDF/Office 工具提取；扫描件仍需页面核读 |
| 精确核验 | SymPy | 定位其他 Python；仍缺失则按当前权限安装或说明范围，不能假称已跑核验 |
| 公式与中文 PDF | XeLaTeX、ctex、中文字体 | 检查系统或宿主编译器；保留源稿，不伪造 PDF |
| PDF 检查与渲染 | pypdf、Poppler 的 pdftoppm | 寻找宿主 PDF 渲染工具；没有页面图时不能声称完成目检 |
| 数学图 | TikZ/PGF 或 Matplotlib；Pillow 可辅助 | 只在有解释价值时使用；不以 AI 图片替代精确数学图 |
| 打包 | Python 标准库＋pypdf | 不需要网页、TeX 或所有绘图库 |
| 组卷网 | 当前可用检索工具、浏览器和访问权限 | 使用可读取的公开题，或由用户完成登录；如实记录缺口 |

脚本不自动安装依赖、不下载题库、不登录网站、不上传学生资料。运行环境、字体、账户和插件工具不封装进本技能 ZIP。根据实际任务补齐所需环境即可，不为只打包或改反馈的任务准备整套编译环境。

## 维护边界

- 本目录仅存通用方法、模板和脚本；学生姓名、作答、原题图、成绩、题源会话和产物放具体项目，不带进可移植技能包。
- 模板给出默认品牌和版式；班级、章节、学生数量、题量、试卷范围由本批证据决定。
- 更新用户偏好时同时检查主流程、模板和打包范围是否一致；升级版本前实测受影响脚本。
- 不把某一历史批次的检查数量、页数或数学结论作为通用保证，不编造第三方引用、技能执行记录或来源关系。
