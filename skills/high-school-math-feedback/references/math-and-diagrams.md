# 规范解析、SymPy 与数学图

## 学生可读的规范解析

以“解：”或“证明：”起笔，按学生已学方法写清必要步骤：换元定义与范围；已知角和目标角关系；公式、代入和中间计算；负号、括号、系数；开方符号；分类去留；除式非零和定义域；端点及增失根；最值的界、等号和可达性；最后回答所求量。

不机械套统一小标题，不只给结果或教师速记，不把工具日志和题源审核放进学生解析。口语化督促保留在学习反馈。

## 精确核验

使用当前可信 Python 与 SymPy。用 `Rational`、`sqrt`、`pi` 表示精确值，假设只能来自题目。可从 `scripts/math_checks.py` 导入 `MathChecks`：

```python
import sympy as s
from math_checks import MathChecks  # 先将技能 scripts 目录加入 sys.path
x=s.symbols('x', real=True)
c=MathChecks()
c.equal('T1', s.sin(x)**2+s.cos(x)**2, 1, 'x为实数', '恒等式')
c.condition('T2', s.Rational(5,6)>s.sqrt(2)/2, '两数均为正', '范围比较')
c.write('math-report.json')
c.require_passed()
```

本批核验脚本须从实际题面重建表达式与条件；不能把示例运行成功冒充全批验证。每个已布置的唯一题目 ID 都须有对应核验或人工一般证明；重复用题可复用记录。

`assumptions` 参数是报告文字，不会自动改变符号假设；须在 `symbols`、区间限制和单独条件检查中落实。多项检查可用不同检查 ID 并传 `question_id='T1'`，用 `require_coverage(实际题目ID列表)` 检查遗漏，再执行 `require_passed()`。覆盖到某题仅说明存在记录，还需核对记录是否真正覆盖关键结论与限制。

- 恒等式核两边之差；方程显式给实数域，保留分母排除值，候选解代回原式与题给范围。
- `ConditionSet` 是尚未求解，不是无解；`None` 是未知，不是通过。`nsolve` 局部根不代表全体解。
- 根式、绝对值、对数幂和复数分支不靠强制化简抹去条件。实数 $x$ 才有 $\sqrt{x^2}=|x|$。
- 不等式与最值保留一般推导、端点和可达性；数值抽样或有限枚举不能证明无限范围。
- 工具验出相等，不说明学生解法已合规；坐标数例不能代替一般几何证明。
- 不把网页/OCR 字符串交给 `eval`、`parse_expr`、字符串 `sympify` 或 `lambdify`；从核读题面构造可信对象。

报告题号、目的、假设、实际检查、结果和限制；未知不当通过。只有脚本实际成功且覆盖核实后才说已核验，原批分数不自动修改。

## 数学图

图能解释范围、单调性、交点、几何关系或分类时才添加；纯公式题不为装饰配图。

### TikZ

几何图、数轴、单位圆和精确坐标图可用 TikZ。先列已知关系、推导坐标与交点，核对平行、垂直、等长、点序、角标及参数。程序角度单位与数学弧度明确换算。

学生题图只显示已知条件，不自动加解题辅助线或答案；知识图、解析图可添加并说明。沿用正文风格，普通编译优先，不无故启用 shell escape。数学逻辑检查与渲染目检分别记录。

### Matplotlib

函数图与参数曲线用 `Agg` 后端、`fig, ax` 接口。断点分段，不跨渐近线连线；几何比例一致，区间端点用空心／实心区分。黑白打印仍可区分线型，先确认中文字体。

优先矢量 PDF/SVG；位图按印刷尺寸给足分辨率。保存后关闭 figure，查看实际输出，检查标签、坐标轴、关键点和裁切。示意图不保证比例时说明，不能从外观添加题目条件。
