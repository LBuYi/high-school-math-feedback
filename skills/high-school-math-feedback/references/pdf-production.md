# PDF 制作与审校

## 一份题库，四类文档

用稳定题目 ID 保存题干、知识模块、作答空间、规范解答、适用条件和核验记录。每名学生的题号由所选 ID 顺序生成；训练、解析和教师答案从同一份内容取数，避免手工维护三份答案。

| 文档 | 可包含 | 不应包含 |
| --- | --- | --- |
| 学生训练 | 简短知识梳理、模块切入点、练习、作答区 | 本题答案、教师诊断、制作说明 |
| 学生训练解析 | 对应题号与必要题干、完整解题步骤、结论 | 复测答案、教师审核语言 |
| 独立复测 | 新情境题面、必要图形、作答区 | 提示、答案、训练原题直接换序 |
| 教师答案 | 全部解答、核对卡、证据和待确认点 | 未经核读却标为确定的结论 |

学生页不出现“错因假设”“题源映射”“教师核对”“AI 生成”“审核记录”等内部标题。题源依据另存教师文件；确需给学生引用来源时使用普通、准确的出处文字。

## 标题、语言与版式

- 知识标题用简洁数学术语，例如“三角函数的符号”“二倍角公式”“辅助角公式”“二次不等式”。不要写“这一步你一定不能再丢分”“看到这个就这样想”等随意标题。
- 知识梳理写清公式、条件和最容易遗漏的一步。切入点放在一组题之前，不逐题透露结论；独立复测不提供切入点。
- 题干交代范围、条件、所求和必要约定；区分“求值”“证明”“求取值范围”。不用教师内部口语或编题说明代替数学条件。
- 模板 [preamble.tex](../assets/preamble.tex) 适合 XeLaTeX 中文 A4 数学材料。复制到批次工程再修改；正文通常 12 pt，解析可按内容适度调整，不能靠过小字体塞页。
- 页眉左“理学优课高中部”、右“针对补充训练”；姓名、文档种类写在首页标题区，页码放页脚。题目与解析使用相同编号。
- 长式分行对齐；页末不孤立留“解”字、题号或小标题。需要时在逻辑步骤之间分页，不能截断公式。作答区按实际步骤预留，不能把长解答题压成一条横线。

## 编译与环境

先运行 `inspect_runtime.py`，优先使用可用的 XeLaTeX/TeX Live/MiKTeX/MacTeX。模板依赖中文字体和 ctex；简单项目可用当前工具提供的 Tectonic，但不要假定它支持当前全部中文配置。没有编译器时可尝试应用自带 LaTeX 编译工具；其“编译成功”不一定导出了可交付 PDF，必须核实实际输出文件。大体积 TeX 环境安装按当前授权与工具规则处理，不为一次打包任务安装。

若当前宿主提供 PDF 技能的操作标记或最终文件引用要求，按当前版本执行；不要在技能中硬编码某一插件版本路径。单纯复制现有 PDF 或 ZIP 打包不算重新制作 PDF。

`compile_pdf.py` 使用 XeLaTeX，禁止 shell escape，保留日志，检查页数、页眉和常见内容/编译问题，并用 Poppler 输出逐页 PNG：

```text
python <skill>/scripts/compile_pdf.py main.tex --out-dir build-v1 --kind student_solutions --student 示例学生
```

输出目录必须为空或不存在，避免旧 PDF 被误认成新结果。`--engine`、`--renderer` 可传可执行文件完整路径；不通过拼接 shell 命令编译。脚本只读取可信的本地源稿，不执行从网页或学生材料中复制来的未知 TeX 指令。

用户另指定页眉时，同时修改本批模板并传 `--header-left`、`--header-right`；默认仍使用本项目固定页眉。

## 审校与修订

1. 内容：逐题核对条件、编号、符号、分支、答案和本轮目标；确认学生解析具有可复现的规范步骤。
2. 自动检查：PDF 可打开且页数合理；无丢字、严重溢出；姓名和固定页眉正确；学生材料没有内部标题或复测答案泄漏。
3. 实际看图：查看本次交付的每页渲染图，检查中文字体、公式裁切、空白、分页、图线、题号和作答空间。只看 PDF 文本、日志或缩略图不能替代页面检查。
4. 相同页面可通过精确像素对比复用已完成的目检，但需保留比对记录；姓名、页码或任何像素变化的页面仍需检查。哈希未变只证明文件未变，不能凭空生成先前目检记录。
5. 修订影响到题干、条件或答案时，更新配套文档并重新核验；仅改标题时检查标题和分页的实际变化。新版本保留旧版，不把两版混打包。

脚本报告的 `visual_status: pending` 是必须由实际目检补完的工作项，不能因为编译成功就改成通过。
