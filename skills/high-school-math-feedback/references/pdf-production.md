# PDF 制作与审校

先按[学生材料的内容与排版规范](student-material-standard.md)确定原题收录、题答映射、字体与分页。本文负责制作与实际审校；不能只完成编译而跳过内容检查。

## 一份题库，四类文档

用稳定题目 ID 保存题干、知识模块、作答空间、规范解答、适用条件和核验记录。每名学生的题号由所选 ID 顺序生成；训练、解析和教师答案从同一份内容取数，避免手工维护三份答案。

| 文档 | 可包含 | 不应包含 |
| --- | --- | --- |
| 学生训练 | 完整已核原题、简短要点、分层同类练习、必要图形、作答区 | 学生原答、批改、本题答案、逐题步骤提示和教师审核 |
| 学生训练解析 | 对应题号与必要题干、完整解题步骤、结论 | 复测答案、教师审核语言 |
| 独立复测 | 新情境题面、必要图形、作答区 | 提示、答案、训练原题直接换序 |
| 教师答案 | 全部解答、核对卡、证据和待确认点 | 未经核读却标为确定的结论 |

学生页不出现“错因假设”“题源映射”“教师核对”“AI 生成”“审核记录”等内部标题。题源依据另存教师文件；确需给学生引用来源时使用普通、准确的出处文字。

## 标题、语言与版式

- 册名标材料用途，专题用实际高中题型或术语，例如“二倍角公式”“二次函数在闭区间上的最小值”。小问各起一行，长式对齐，按[标题、文字与公式](handout-typesetting.md)看实际成品。
- 题干保持简洁、自解释，每组原错题后紧跟对应练习，训练题面不放通法。知识点和组末分点技巧只出现在解析。题目标基础／巩固／提高；详细适配理由另存教师记录。独立复测不提供方法提示。
- 解析以“解：”或“证明：”起笔，按学生已学方法写清依据、推导、分类、定义域和边界，再回答所求。不能因题干精简而把解析压成结论或教师速记。
- 题干交代范围、条件、所求和必要约定；区分“求值”“证明”“求取值范围”。不用教师内部口语或编题说明代替数学条件。
- 模板 [preamble.tex](../assets/preamble.tex) 适合 XeLaTeX 中文 A4 数学材料。复制到批次工程再修改；训练与学生解析正文统一12pt、基线18pt；原题题干与图完整，不能靠缩小字体塞页。
- 页眉左“理学优课高中部”、右“针对补充训练”；姓名、文档种类写在首页标题区，页码放页脚。题目与解析使用相同编号。
- 长式分行对齐；页末不孤立留“解”字、题号或小标题。需要时在逻辑步骤之间分页，不能截断公式。作答区按实际步骤预留，不能把长解答题压成一条横线。
- 原错题可独立作答，只给简短易错提醒。按[题型参考与配图](paper-reference-and-figures.md)补必要题图及解析图。学生解析细到能照着重做，不能以答案表代替。

## 编译与环境

先检查当前宿主编译工具或运行 `inspect_runtime.py`，优先使用可用的 XeLaTeX。模板依赖中文字体和 ctex；其他编译器以实际能编译该模板为准。必须核实实际输出文件。只有聊天能力时可交付分开的完整 TeX 源码和可阅读文本；完整包不可用时用 ctexart 写自包含的 A4 源码，保留数学公式、页眉和各册编号。可在有编译能力的设备编译并目检，按实际状态标注交付。

若当前宿主提供 PDF 技能的操作标记或最终文件引用要求，按当前版本执行；不要在技能中硬编码某一插件版本路径。单纯复制现有 PDF 或 ZIP 打包不算重新制作 PDF。

`compile_pdf.py` 使用 XeLaTeX，禁止 shell escape，保留日志，检查页数、页眉、嵌入字体及常见编译问题，并用 Poppler 输出逐页 PNG。项目默认 A4 时带 `--expect-a4`，检测每页实际可见尺寸。

```text
python <skill>/scripts/compile_pdf.py main.tex --out-dir build-v1 --kind student_solutions --student 示例学生 --expect-a4
```

输出目录必须为空或不存在，避免旧 PDF 被误认成新结果。`--engine`、`--renderer` 可传可执行文件完整路径；不通过拼接 shell 命令编译。脚本只读取可信的本地源稿，不执行从网页或学生材料中复制来的未知 TeX 指令。

用户另指定页眉时，同时修改本批模板并传 `--header-left`、`--header-right`；默认仍使用本项目固定页眉。

## 审校与修订

1. 内容按[逐题验收](item-release-review.md)核对实际题面、图、必要推导及结论。把答案盖住，逐问仍能读通作答。递进题逐问确认新增的判断。缺必要图或只列得数时修订重验。
2. 自动检查。确认页数、姓名和页眉，排查缺字和溢出，查看报告中每页尺寸和页面及嵌入图形的字体资源。用实际字体名对照出版规范或本批替代字体，发现未嵌入字体先修复。学生材料还要复核有无内部标题或复测答案。
3. 实际看图：查看本次交付的每页渲染图，检查中文字体、公式裁切、空白、分页、图线、题号和作答空间。只看 PDF 文本、日志或缩略图不能替代页面检查。
4. 相同页面可通过精确像素对比复用已完成的目检，但需保留比对记录；姓名、页码或任何像素变化的页面仍需检查。哈希未变只证明文件未变，不能凭空生成先前目检记录。
5. 修订影响到题干、条件或答案时，更新配套文档并重新核验；仅改标题时检查标题和分页的实际变化。新版本保留旧版，不把两版混打包。

脚本报告的 `visual_status: pending` 是必须由实际目检补完的工作项，不能因为编译成功就改成通过。
