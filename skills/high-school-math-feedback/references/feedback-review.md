# 审查反馈与订正

用于审阅已有反馈、把学习建议写得能执行，或核对已回收的订正。对照本批已经核实的题目与作答。只有旧反馈稿时，可改语气和表达，原答、分数及教学安排仍以提供的材料为准。

## 写之前核对三件事

| 要核对的内容 | 看什么 |
| --- | --- |
| 结论从哪里来 | 能指到题号与一行原答。把已做对的部分、最早可见的偏离和还缺的证据分别记清。正确选项与正确推理分别核对，有效的其他解法同样认可。 |
| 孩子能先做什么 | 从重要问题里选一处，指给孩子看具体题目、条件或一行式子，说清要补写、解释或检查哪项内容。已有训练时核对实际题号。需要新的前置知识时，先补那个知识或给一个适当例子。 |
| 做过之后看什么 | 用一句话约定老师可核对的作答，例如“能写出两个端点各能不能取到，并说明理由”。记录原题订正、提示后完成或独立新题的实际表现。 |

优先选一个能马上完成的订正动作。学期安排、时间或提交方式已确定时才写入消息。只润色的任务保留原稿事实，新增的教学动作可以写作建议。家长版采用[教师口吻](teacher-voice.md)和[家长反馈](family-feedback.md)，上表留作老师审阅用。

先校对内容，再顺口吻。每段能找到一处真实作答，以及从这处作答直接引出的建议。已经在题后说清的动作无需收在末段重说。最后再核对稿件中的题号、已配材料和计划时态。若需要改动训练或复测，沿[全流程复核](workflow-review.md)核对受影响的文件。

## 根据证据选择下一步

- **只有结果。** 先问“当时用了题目里的哪个条件，能把第一步写给我看吗？”需要区分两种想法时，可以给一对只改一个关键条件的短题。选择题的错选项用于提出候选解释，结合学生自己的理由再判断。
- **原答有清楚的偏离。** 从最近一处正确步骤重写。可点出要检查哪个条件，留给孩子自己做判断和计算。条件本身没理解时，换一个例子讲清，再回原题。
- **答案对，理由缺或不成立。** 点明需要补哪一条依据。有过程能确认不等价变形时，可让孩子检查原式与变形所得的条件。采用教材范围内的另一种正确方法时，按数学理由核对，教师的书写要求按已知规则另记。
- **已经看过提示或答案。** 可以回看原题，确认能解释方法。下一次独立检查用新题，并选择足以检验同一步骤的条件变化。完成订正和独立作答分别记录。

## 一个虚构的核对例子

原题求 \(f(x)=x^2-6x+8\) 在 \([0,2]\) 上的最小值。孩子正确配方为 \((x-3)^2-1\)，直接把顶点值 \(-1\) 写为最小值。区间在对称轴左侧，函数在区间上单调递减，所以最小值为 \(f(2)=0\)。现有作答能确认漏查取值点，深层原因可再用独立作答核对。

老师发给家长可以这样写：“这道最小值题，孩子前面的配方没问题，后面少看了题目给的区间。订正时可以从配方那一行接着写，先把顶点的横坐标和区间对照一下，再写明为什么选这个点取最小值。先留一下自己做的过程，碰到拿不准的地方再看解析。”

若须复测，可换成求 \(g(x)=x^2-2x+4\) 在 \([0,2]\) 上的最小值。对称轴这次在区间内，最小值为 \(g(1)=3\)。这道题检验孩子会不会根据位置重新选取值点。独立复测的题面仅给题目和必要条件。

## 发出前通读

从家长和孩子的角度读一次。家长能说出这次具体卡在哪，孩子知道可以从哪里写起，建议与本轮已提供的练习一致。给出图、步骤或完整答案前，先看本轮是否需要保留独立尝试。面向实际教学的采纳情况以收到的作答为准。
