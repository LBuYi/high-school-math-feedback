# 学生材料的内容与排版规范

这是本项目的默认出版规范。用户指定特殊要求时调整对应参数；不要因题数、页数或既往模板而删去原题、压小字体或简略解析。

## 原错题必须进入学生材料

学生训练按每个问题组织“原错题 → 简短要点 → 对应的同类练习”，不能只在教师档案中保存原题，也不能只给一批相似题。原题与新题分别保留原卷题号和训练题号，解析据此对应。

- 原题完整保留已核对的题干、选项、量词、范围、图形和所求。某小问依赖前文时，连同前置定义、条件和必要小问一起收录；不得用“同原题”“见上问”替代缺失材料。
- 默认用标准数学格式重排原题；图形难以忠实重绘时，使用清晰的原图裁切。题干有疑点则先核对，不从学生答案倒推。原始文件保持不变。
- 原答与教师批改仅在教师档案中保留，并标出原卷页码、答题卡位置和对应题号。学生页只保留原题题面供回看。仅保留结果时，不推测学生用了哪种方法。
- 原题作为独立的重做题，按实际书写量留空。靠近原题的补充只放一两条易错提醒，不印该生错答、不提前亮答案或提供逐步提示。是否布置这部分由本轮安排决定。
- 相似题须对应原错因，而不只看表面题型。基础题查原错误动作，变式查条件变化，综合题查独立迁移；目的及题源放在教师记录，学生题面不逐题加方法提示。
- 同一个目标关联多道原错题时，可以合并编排，但保留各次原题和证据。月度整理也遵守这个结构，不能把原题仅换成知识点名称。

## 交付各自承担的内容

| 材料 | 应包含 |
| --- | --- |
| 学生训练 | 原错题、简短要点、对应练习和作答区，按原题与目标成组 |
| 学生解析 | 原题与训练各自对应的规范解答；完整题面已在训练册时，解析按题号书写，保留必要题意即可，不必重复整段题面；不夹带复测答案 |
| 反馈文字 | 回复正文中直接给出的可转发文字，说明本人的问题和具体建议；可另存TXT |
| 独立复测 | 对应原目标的新题、必要图形、作答区，撤去方法提示 |
| 教师档案 | 原题来源和页码、原答及批改、首次偏离与判断限度、题源适配、题答映射、核验和真实复测状态 |

无需为每道题堆叠“知识点、解题切入、条件辨析、独立训练”等栏目。主标题、必要的数学专题、原卷题号与练习题号即可区分层次。学生题目用基础／巩固／提高作简短分层；详细适配理由、题源审核、生成工具及审核过程留在教师记录。

## 字体、字号与页面

| 对象 | 默认值 |
| --- | --- |
| 页面 | A4纵向，单栏，黑白打印；左、右20mm，上24mm，下20mm |
| 中文正文 | 宋体，小四12pt；训练与学生解析相同 |
| 正文英文、数字 | Times New Roman；数学表达式中的字母与数字使用数学字体 |
| 数学公式 | Cambria Math，正文基准12pt，变量斜体，函数名及运算符正体；分式、根号、上下标正规排印 |
| 主标题 | 黑体18pt，姓名栏12pt |
| 数学专题标题 | 黑体14pt；题号／原卷题号12pt加重，不逐题另加考点标题 |
| 行距与段距 | 正文基线18pt，段后4pt，首行不缩进；独立公式上下各6pt左右，长式按等号或不等号分行对齐 |
| 页眉、页码 | 宋体10.5pt；左“理学优课高中部”，右“针对补充训练”，页脚居中页码，页眉细线0.4pt |

宋体、黑体、Times New Roman及Cambria Math只引用本机已安装字体，不随技能分发字体文件。缺字体时用同类可用字体替代，例如Noto／思源宋体与黑体、Fandol、TeX Gyre Termes Math或Latin Modern Math；记录实际字体，并重新查看分页，不能声称不同设备生成的页面必然一致。模板见 [preamble.tex](../assets/preamble.tex)。

不通过缩小到五号字、压缩公式或减少必要步骤来塞页。数学图通常用10.5—12pt标注，线型和关键点在黑白打印中仍应可辨；题图只给已知条件，解析图可以展示必要辅助关系。

## 作答空间与分页

- 先估计书写步骤，再给空间：选择判断需说明理由时约20—35mm；常规解答约45—70mm；分类或综合题约75—100mm。数值为起点，以实际题目为准，不统一塞成每页三题。
- 一道训练题的题干与作答区尽量放在同一页。长题超过一页时按小问分；不要让上一页只剩题干，下一页只有空白。原题以题干完整为先，图形与相关条件放在一起。
- 多问先写共用题干，各问顺次分行，整题后统一留一个作答区。解析对应的各问单独成块，关键式、分情况和结论按逻辑另段。按[讲义排印规则](handout-typesetting.md)看最终两册。
- 解析允许跨页，在小问或一段完整推导之间分开；页末不孤立题号、“解：”或一行条件。避免一个方程组、分段式或半个公式被截断。
- 简短要点用正文大小，段首可加粗“要点”，正文与段首标签同一行。用模板的 `\keypoints` 或保留约6pt的上下间距，使原错题、要点和练习易区分。
- 框线只在必要时使用。默认无卡片、灰底、彩色徽章和装饰图标；最终答案可以局部标明，不给每个中间式加框。
- 作答区按总书写量调整，题量按目标和负荷决定；增加原题回看后重新估计学生用时，不能沿用旧版预计时间而不说明。

## 题干、解析与反馈分别写

题干用高中常见、准确的数学叙述，保留对象、范围、量词和所求。每组原题后适当补充简短知识与解题通法，按判断分点，不逐题附步骤提示。函数命名、难度分层和适配记录见[训练设计要求](problem-adaptation.md)。适合递进的题按[数学递进小问](math-progressive-questions.md)设计。标题、题干和公式按[讲义用语与排印](handout-typesetting.md)终审。独立复测不加方法提示。

解析用“解：”或“证明：”起笔，交代公式依据、等价条件、必要中间计算、参数分支、定义域、端点及结论。使用学生已学方法。题干精简不等于解析简略；也不把口语化督促写成数学证明。

反馈沿用[教师口吻](teacher-voice.md)：默认老师向家长说明孩子的情况，孩子也能理解；明确要求学生版时用“你”。用真实的一两处步骤说明主要问题，再顺着说课下怎样处理，见[家长反馈](family-feedback.md)。通常2—4个自然段即可，篇幅随问题而定，不凑固定字数。每段讲一个实际问题，不套“问题表现／改进策略／行动计划”的报告栏目。删掉无依据的“总是、又忘了、讲过很多遍”，也不统一用错题本、定期复测等流程话收尾。批评有分寸，保留已经做对的部分和不确定性。

## 交付前检查

1. 每个选定原错题都在学生训练中出现，题干、选项、图与依赖条件齐全。原答与批改能在教师档案中回查。
2. 每道训练能映射到原题和训练目标；原题、练习、解析、复测编号无混淆，数量和预计用时按本版记录。
3. 按[逐题验收](item-release-review.md)独立核对数学结论和成品。需要的题图不缺，选填有依据，解答题每问有理由、关键式与取舍。学生只有答案时不捏造原作答过程。
4. 对照实际 PDF 核对纸型、字体名称和嵌入状态。保留脚本检查结果或实际检查记录。逐页查看页眉、字形、公式、分页和可书写空间。实际替换了字体时，记录替代名称并复看变化的页面。
5. 学生包只含最新有效训练、解析和反馈等已请求材料；旧版保留。新增原题不代表已经布置、完成或掌握。
