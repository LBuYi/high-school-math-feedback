# 老师发给家长的学习反馈

默认交付可直接发送的老师消息，家长与孩子都能理解。只在用户要求时另出学生版。

## 写之前先定要讲什么

起草前先说清这次最想和家长沟通什么，再挑有代表性的作答。整卷有足够证据时，可以先说孩子在什么题上已经有思路，再讲最影响得分的一两类问题。选填里只有答案、值得回头补过程的，也可带一句具体建议。分数用于交代语境，跨次变化要有可比作答。

让家长看懂孩子为什么在这一步卡住。比如说“代进去的式子也要在函数允许的范围内”，再结合该题说明少了哪个限制。完整推导留给解析。围绕主要问题安排题目举例，篇幅随已有作答和这次需要沟通的内容决定。

## 顺着题目把建议讲完

直接从关键一题讲起也可以。原答能看出做对了什么、在哪一步偏了，就从这一步接着说怎么改。两题是同一类问题时，用一题把道理说清，另一题简短照应。两个问题各有明确证据时，建议放在各自的问题后面。只看到最终答案时，先请孩子说说起点或补一行依据，原因留待核对。

建议具体到孩子动笔时要补的那一步。数学上重要的地方，可以像平时讲题一样多说两句，交代漏掉后为什么会算偏，或者题目换个条件后该怎么重新判断。已有练习可以说先做哪两题及其用途。确实适合记易错点时，说清要记哪个条件，什么时候回顾能用得上。复测日期或家长配合有实用信息时再交代。

这套顺序用来选内容和检查因果，正文按真实作答自然组织。题号和建议的核对见[反馈审查](feedback-review.md)。

## 自然、关心，也有督促

关心体现在承认可见的正确步骤、缩小本轮重点、给出能完成的安排，并说明困难仍可继续处理。不能为了显得亲切编造“孩子很努力、最近压力大、我一直在关注”等观察，也不靠“放心、一定会提高”替代判断。

督促写成具体学习要求，例如“配完方后，还要看顶点在不在区间里”“做过的题也得说明为什么这样分情况”。避免“全靠家长监督、别再粗心、态度必须端正”等无证据责备。历史确有反复错误时，可以明确提醒，但仍说明反复在哪一步。

称“孩子”通常足够；姓名和“他／她”按已知信息使用，不从姓名猜性别。“家长您好”可用于正式开头，已有聊天上下文时可直接进入学习情况。不要每段都重复称呼，不强制先夸后批或写满固定段数。

## 谁做什么要清楚

| 内容 | 怎样表达 |
| --- | --- |
| 孩子要做 | 一个具体订正动作、对应练习或必要回顾；题量服从实际安排 |
| 教学侧处理 | 依据已确认的安排说明讲解、选题或核对；未确认时写建议，不代老师许诺“下节一定逐题辅导” |
| 家长可配合 | 有帮助时提出一项简单、可选的提醒或情况反馈；不要求讲题、判题、辨别代数错因或每天新增打卡 |

不是每份反馈都要写齐三方任务。纯学科问题可以只讲孩子怎样练；需要家长反馈用时、负担或完成困难时再自然提出。收到的意见与教学安排分开记录，不把“家长说看懂了”记作学会。

## 确定程度和时态

- “这次少写了一个范围”是作答事实；“不理解范围”是原因判断，需过程、解释或新题支持。
- “只有答案，还要看过程”不写成“孩子做题跳步”；看不清的图也不能补成确定的算错。
- 已生成练习可说“这份练习”，未生成只说建议配什么；尚未收到复测不说“已经改善”。
- 用户确认过的下轮安排可以转成老师的未来计划，仍保留计划时态；不要编造已讲过、已联系、已跟进。

## 修改常见的生硬说法

| 待改表达 | 应怎样处理 |
| --- | --- |
| “存在条件核查不到位的问题” | 具体写哪一步漏了什么，如“配方做对了，后面还要看看顶点在不在区间里” |
| “建立检查机制，形成闭环” | 写本题真正需要的检查，不把内部流程术语发给家长 |
| “建议加强监督，提高重视程度” | 如确需家长参与，说明简单可做的配合；否则删去，补上孩子本人的学习动作 |
| “基础扎实，潜力很大” | 有证据就说具体会了哪一步；没有依据不补表扬 |
| “只要坚持就一定能提分” | 保留希望达到的目标，进步要看后续完整独立作答 |

这些是判断示例，不是词语黑名单。不要把“加强”逐字换成“多注意”就算自然；还要核对整段的事实、因果和语气。

“不从一次错误判断习惯”“收到独立作答再判断掌握”等是写作和审核规则，通常不逐句念给家长。正文直接讲本人的问题、练法和有依据的安排；需要说明尚缺过程时再自然说明，不把每份消息写成评估免责声明。

## 成稿检查

先拿原答、已配练习和已确认安排逐句核对。再把正文当家长微信读一遍。整卷稿应让家长能说出孩子已经做到哪里、为什么还要练、回去先做什么。段落像连续几句批注时，补上前后关系和理由。删掉替家长或教师添的任务、重讲上一段的结尾。

如果提到进展，把这次改了哪一步说清楚。例句“按提示补写了分母的符号判断”与“换一道题也能自己写出这一步”各有相应的作答证据。部分题没交时，反馈只覆盖已经收到的题。
