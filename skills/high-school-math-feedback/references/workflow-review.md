# 全流程复核

审查整套流程或完整交付前，用一份有代表性的作答逐环核对。只处理反馈时以材料核读和家长稿为范围。核对结果并入现有教师卡和交付记录。

| 环节 | 核对依据 | 需要回到哪一步 |
| --- | --- | --- |
| 收齐材料 | 原卷题号、必要条件、图以及答题卡区域对得上。已辨认的作答与教师批改分开记录。 | 页序或配对存疑时先核对原件，只交付已经确认的部分。 |
| 选目标 | 已正确的步骤和首个可确认的偏离清楚。仅有答案时保留待验证的原因。 | 无法指出原答就缩小判断，先用短问或对照题查原因。 |
| 写反馈 | 主要判断有题目证据，孩子知道先补的一步。接收人、题号及时态与交付一致。 | 语气生硬先梳理重点与段落关系。建议泛化时回到原答。参见[家长稿](family-feedback.md)。 |
| 筛题和验题 | 原题、练习与新题共同指向可观察的动作。按来源实际核读，原题和每次改编均独立解答。 | 附加知识挡住目标动作就换题。题面或结论有歧义先修复必要条件，再更新解析。参见[筛题](question-research.md)和[数学校验](math-and-diagrams.md)。 |
| 排印与发放 | 反馈可复制，原错题完整入册，卷、解析、复测分开。纸型、字体、页眉与题答映射经过核对。 | 修改题面后同步相应解析与复测关系。改字体或分页后检查实际页图。参见[制作与目检](pdf-production.md)和[交付](retest-and-delivery.md)。 |
| 复测和存档 | 只按收到的题更新。核对出来的结论、关键步骤和获得的帮助都能追到真实作答。 | 只给结果时等补理由。提示后能做，另用新题观察独立表现。参见[作答记录](records-and-review.md)。 |

### 教师卡上的一行对应关系

每个核心目标沿一行核对“原卷题号和所见步骤 → 同类练习题号及要写的一步 → 换题后仍要观察什么 → 当前实际状态”。详细原答、解法、来源和核验留在已有档案。发出前看目标与材料，收回后看对应步骤。遇到不清楚的材料保留待核对。

## 选题示例

以下题目为虚构，用来示范筛选。学生做含参数的分式不等式有解问题时，从分式中减去 1 却漏减整个分母。目标是在确认分母为正后写出完整的等价不等式。

- 核心候选。若不等式 \(\dfrac{2x^2-mx+m+2}{x^2+1}\le 1\) 有实数解，求 \(m\) 的取值范围。学生需要判断分母恒正，再把分子减去整个分母。得到 \(x^2-mx+m+1\le 0\)，故 \(m^2-4m-4\ge 0\)，即 \(m\le 2-2\sqrt{2}\) 或 \(m\ge 2+2\sqrt{2}\)。
- 方法参考。若直接给出 \(x^2-mx+m+1\le 0\) 并要求有解的参数范围，练到的是判别式。可用于回顾后半段通法。
- 新题复测。改变分母及右端常数，例如 \(\dfrac{3x^2-mx+m+4}{x^2+x+1}\le 2\) 有实数解，求 \(m\) 的取值范围。题面不附步骤。判据包含分母恒正与等价式 \(x^2-(m+2)x+m+2\le 0\)。判别式为 \(m^2-4\)，所以 \(m\le-2\) 或 \(m\ge 2\)。只提交这个结论时，仍要核对目标步骤。
