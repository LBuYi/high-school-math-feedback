# 复测、归档与交付

题目、作答事件、流程状态与目标表现分别记录，见[作答事件与月度记录](records-and-review.md)。家长反馈按[家长沟通](family-feedback.md)写，历史学生版原稿保留。

## 复测依据

复测与本轮目标对应，通常另配 1—2 题；至少改变数据或表达，必要时改变情境，检查同一关键步骤能否独立迁移。先确定判据，例如“能由角的范围判断符号，并在求值中正确选择根”，不要只写“正确率提高”。

约定日期在线提交完整作答及实际用时，附是否看过提示或解析。可随提交说明，版面上保留必要字段即可。每道题分开核对目标步骤和最后结果。日期未约定时标“待约定”。独立性根据已知完成条件记录，学生自述时写清依据，情况不清时留待核对。

| 状态 | 可记录的事实 | 后续处理 |
| --- | --- | --- |
| 待复测 | 尚缺符合要求的新作答；另记材料是否已生成及实际布置 | 等待完整独立作答，不提前判断能力 |
| 提示后完成 | 在帮助后得到正确结果 | 换题检查独立完成 |
| 核心步骤通过 | 已独立写出目标步骤，迁移还未核实或表现不稳 | 按需补一次短练或复测 |
| 本轮初步通过 | 核实独立完成核心步骤和本轮要求的变化 | 按周安排下一轮，后续可抽查 |
| 延时保持 | 间隔后同类题仍独立通过 | 可暂时关闭本目标，保留证据 |
| 仍需巩固 | 原有错误重现，或前置困难实际妨碍目标步骤 | 缩小目标，补关键环节再测 |

一次复测通过只能支持本轮结论，不写成永久掌握。记录实际提交日期、独立性证据、题号、关键步骤和下一步；原成绩和教师原批改不改写。

复测只交了第一题时，核对第一题及其对应目标，余题保持待提交。答案写对但关键理由缺失时，可先补问相应依据，结论暂记“结果正确，步骤待核”。独立作答中出现无关的新失误时，单独记录新问题，同时保留得到验证的原目标表现。

## 月度错题集

按实际作答日期归入对应月份；未知日期留待核对。聚合同类训练目标时保留各次原题、错误证据与复测结果，避免把重复错误当成重复文件丢掉。学生版按“原错题→对应同类练习”成组，完整保留核对过的题干、必要图与条件；原答摘录只写可确认内容。组前可用简短要点补充知识与通法，练习只标基础／巩固／提高；详细适配理由留教师记录，独立复测无方法提示。复测与解析另发。教师记录列本月反复出现的目标、已有进展及还需核对的点。

## 版本与材料分层

每批保留原始输入、可编辑源稿、题目/证据/来源记录、核验报告及交付文件。可按以下结构组织，不要求重排已有稳定工程：

```text
批次目录/
  原始材料/           原件只读副本
  制作源稿/           题库、TeX、图、核验脚本
  教师记录/           错因依据、来源、核对卡、检查结果
  交付PDF/学生姓名/   四类 PDF
  反馈文字/           每人 UTF-8 TXT
  student_bundle.json
```

保留旧版，新版明确标识日期或版本。清单只指向本次确认有效的文件；同一学生不得混用新版题面和旧版解析。源稿是可维护记录，学生包只放所需交付。采用新排版时，原题、训练、解析与清单同步检查，当前有效文件不能缺少对应原题；教师端真实原答与批改仍保留。

## 备课整包和个人布置材料

用户明确要求合并训练、解析和反馈时，按既有清单交老师备课整包，每人三份。

1. `姓名_学生训练.pdf`
2. `姓名_训练解析.pdf`
3. `姓名_学习反馈.txt`

老师第一次发练习时，可直接使用对应学生的训练 PDF。已有多人清单且需要 ZIP 时，可按一个姓名提取其训练 PDF。老师按实际进度另给学生解析，家长反馈使用可复制正文。复测试题单独安排。明确要求在备课整包内收录复测题面时，使用 `--include-retest`。

复制 [student_bundle.example.json](../assets/student_bundle.example.json) 到批次目录，填入相对该目录的文件路径，再运行：

```text
python <skill>/scripts/package_students.py student_bundle.json --output 学生资料.zip
python <skill>/scripts/package_students.py student_bundle.json --assignment-for 示例学生 --output 示例学生_练习.zip
```

脚本检查清单中的姓名、文件路径、PDF 可读性及输出内容。`--assignment-for` 需要清单中的确切姓名，压缩包内只写该人的训练 PDF。打包前核对训练字段确实指向该生的练习卷，文件名和 ZIP 校验无法替代这一步。要发答案或复测时，按本轮教学安排选相应文件。

## 桌面与交付说明

明确要求放桌面时，Windows 通过 `[Environment]::GetFolderPath('Desktop')` 读取实际桌面路径；不要猜测 OneDrive 重定向情况。先在工作区完成压缩包并核验，再按当前文件系统权限复制到桌面，核对目标存在、字节数和 SHA-256 一致。遇同名文件时保留旧包或用新版本名，不能静默覆盖。

最终给出可点击的实际文件路径、包含的学生/材料数量和实际完成的核验。有原题缺页、未能读到组卷网原文或待确认作答时，明确对应范围，不用“全部核验”掩盖缺项。不把生成、复制或打包描述成已经发送给学生、学生已经完成或已经掌握。
