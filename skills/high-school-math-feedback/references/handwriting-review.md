# 手写页核读

有文本层的 PDF 可以提取文字做目录。空文字层只说明提取不到可用文字；先检查原页。含手写、圈画、涂改或公式图片的页面使用可见图像。按姓名或匿名编号、原卷、题号和页码先对齐材料。

1. 用宿主 PDF 或视觉工具查看一页概览，再按题号放大局部。没有整页读取工具时，可用下方脚本拆页。文字多栏或算式跨行时保留整页用于定位。
2. 分开转录印刷题干、学生原答和教师批改。保留错写、删改和步骤顺序；不替学生改成正确答案。红笔是线索，身份须按上下文核实。
3. 对照原图复查小问标号、每行行首的正负号、分母、指数、范围、几何标记和批改指向。仍不清楚时标明页码、题号与位置，将该处列入教师核对卡。缺原题时不从答案倒推题干。
4. 外部 OCR 只在用户已授权本批材料、范围和服务时使用。把识别结果当初稿。纯文本 Agent 接收经核对的转录即可，区分原图核对由谁完成。

可交接的核读稿使用以下字段；一页多题时逐题记录。

```text
原卷与页码：
题号／小问：
原题与必要配图说明：
学生原答（逐行）：
教师批改（可见部分）：
待核对位置与候选读法：
转录来源与复核状态：
```

## 本地拆页与裁切

直接使用 Agent 自带的 PDF 渲染器也可以。需要可重复的本地命令时，运行包内脚本：

```text
python <skill>/scripts/prepare_evidence.py <答题卡.pdf> --out <批次>/核读-01 --pages 1-2
python <skill>/scripts/prepare_evidence.py <作答照片.jpg> --out <批次>/核读-02 --rows 3
```

默认准备第 1 页，每页输出概览与三块有少量重叠的局部图。可用 `--cols 2` 分列，`--crop 左,上,右,下` 按 0 到 1 的归一化坐标截取，或 `--pdftoppm <绝对路径>` 指定已安装渲染器。裁切应用于所有选中页；要保留完整证据时先准备原页。

输出目录须是新目录。只有成功时才生成 `manifest.json`，记录原件哈希、实际选页、图片和 PDF 文字层状态。文字层来自整页，即使指定了图像裁切也一样。脚本在本地生成可读页图和文本索引，手写识别及原图复核由 Agent、OCR 或教师完成。全部输入仍应保留原件。
