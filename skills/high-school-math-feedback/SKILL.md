# 高中数学错题反馈与针对训练

先看学生实际写了什么，再决定怎样解释和训练。当前用户指定的接收人、年级、已学范围、批次和交付要求优先；不把历史班级或题量当默认配置。

## 先确定本次做什么

检查项目入口、当前有效技能及交付清单，沿用已经确认的信息。缺项先找文件夹、合卷或ZIP；清楚部分先做，只集中核对会改变身份、题干或判断的缺项。

| 本次请求 | 读取及执行 |
| --- | --- |
| 只分析或写反馈 | 核读原件、独立验题、定位证据，读[材料与反馈](references/materials-and-feedback.md)及[教师口吻](references/teacher-voice.md)，按需给一个可做的订正动作 |
| 审阅已有反馈或流程 | 对照原题、原答和目标读[反馈审查](references/feedback-review.md)；完整流程再按[全流程复核](references/workflow-review.md)追到复测和归档。只有反馈稿时，限定为文字审阅 |
| 整理同卷多人或增量重编 | 先按原件逐人核读，再用[本地批量处理](references/batch-processing.md)登记合并、检查改动并生成各册 |
| 发给家长，或未另指定接收人 | 默认老师写给家长，孩子也能看懂；读[家长反馈](references/family-feedback.md) |
| 明确直接写给学生 | 用“你”，按同一证据写具体提醒；不机械复制家长版或同时多交一版 |
| 按需配训练、变式或复测 | 先读[题源](references/question-research.md)、[题型参考与配图](references/paper-reference-and-figures.md)和[难度与要点](references/problem-adaptation.md)。适合分问时读[数学递进小问](references/math-progressive-questions.md) |
| 整理交付包 | 按[归档与交付](references/retest-and-delivery.md)区分教师备课用整包和个人布置材料 |
| 制作或修订PDF | 读[学生材料规范](references/student-material-standard.md)、[逐题验收](references/item-release-review.md)、[数学核验](references/math-and-diagrams.md)和[制作与目检](references/pdf-production.md) |
| 收回复测、建立档案或做月册 | 读[归档与交付](references/retest-and-delivery.md)及[作答事件与月度记录](references/records-and-review.md) |
| 参考其他项目或征求外部模型意见 | 读[来源取舍](references/comparative-review.md)和[外部审阅](references/external-review.md)；意见只作候选，不替代核验 |

## 核读与诊断

- 保留原题、学生原答和教师批改。先对齐原卷、题号、学生和页码，再独立解题，比较首次有证据的偏离；已正确的步骤也要保留。
- 文字层用于检索，公式、图形、手写和批改仍回看原页。扫描页先渲染，必要时看局部；核对负号、分母、上下标、范围和涂改。读不清保留候选与位置，不修补成正确答案。见[手写核读](references/handwriting-review.md)。
- 分开“观察到的错误”和“可能原因”。分别核对答案、关键依据、解题条件，数学成立的其他解法也可认可。只有一个选项或最终答案时，用中性的短问了解思路，把原因留待验证。完整性不足时先交付可核实的部分。
- 每轮先选一个可验证的目标，紧密相关时合并两个。概念、条件、方法、运算、推理和书写等类别用于选练法，不给学生贴标签；也不把后续连锁错误计成多个独立漏洞。

## 写可直接转发的反馈

默认用老师对家长的语气，称“孩子”，性别无依据时不猜。先定这次最值得讲的判断，再挑能说明它的原答。整卷有足够作答时，用几个自然段讲清做得好的地方、影响得分的主要问题和课下怎么练。沿着具体题目说明为什么要补某一步。只有单题或证据较少时可简短，篇幅随作答而定。写前按[家长稿组织方法](references/family-feedback.md#写之前先定要讲什么)选内容。

家长能看懂问题及配合方式，孩子能明白该练什么。数学讲解、订正和复测核对由教学流程承担；不把责任收成一句“家长加强监督”。家长配合只在有帮助时自然提出，不默认要求家长讲题、判题或增加固定打卡。未发生的辅导不写成已经做过，未确认的计划不替老师承诺。

有可核对的原题或现成练习时，根据原答说清孩子用了什么方法或知识，处理到哪一步，哪里漏掉条件或用错，以及接下来要补写哪一行。看不到过程时不猜方法。孩子先独立订正，有需要只给一点提醒，完整解析另发。用[反馈审查](references/feedback-review.md)核对练习编号、方法条件和所需材料。

示例（虚构）：“这道二次函数最小值题，孩子前面配方已经做对了。订正时从这一步接着写，先看看顶点的横坐标在不在题目给的区间里，再写明为什么在所选的点取到最小值。这一行值得自己补完整，下次题目换个区间也用得上。”

沿用[教师样本](references/teacher-voice.md)，按[高中规范用语](references/high-school-language.md)检查数学条件。反馈用连贯自然段，篇幅按信息决定，不机械先夸后批，不堆题号或报告栏目。润色保留事实、否定和“可能、还需核对”等确定程度。学习反馈须在回复正文中直接给出，可另存TXT；附件不能代替正文。

## 选题与学生材料

新增训练或实质改题时，用浏览器自行打开组卷网到具体题目；教师指定题先核对。只用题目特征搜索，不带学生资料。记录真实链接、题号、实际读到的题干／图／答案及采用的题型结构。不可读时记录具体原因，再用符合本轮范围的公开校卷等核对。区分平台原题、改编、方法参考和新拟，不以列表或摘要当核读。

按[筛题顺序](references/question-research.md#逐题筛选)核查完整题面、目标动作、已学方法与负荷、独立解答。题目须确实练到目标动作，考虑其他正确解法能否绕开它。同章但缺这一动作的题只作方法参考或备选。题量按目标与强度决定，不固定或限定十题。需要帮助才提供示范或补步骤，随后撤去；最终用另配的一至两道无方法提示的新题检查。提示后做对与独立完成分别记录。

完整原错题独立排成重做题，保留必要图表和留白，只补简短易错提醒，不印原答、错选项或批改。知识和方法按组去重，题干不逐题加步骤指令。分层仍用“基础／巩固／提高”，适配理由留教师记录。新编函数优先用f、g、h，原题保留原符号。

目标涉及已学范围内的参数、证明或综合迁移且能自然递进时，至少安排一道 2—3 问，从基本判断推进到条件变化，再让学生分类、反推或证明。先定末问，再留必要铺垫。核对每问新增的判断，纯换数、加运算量和互不相关的小问不当作递进。

解析另册，按[讲义排印规则](references/handout-typesetting.md)一问一块，编号独立成行。依据、等价条件、推导、分类和结论照逻辑分段，关键式另行对齐。遮住答案后仍能读通。先独立推导，有SymPy时复核适用结果。用图判断交点、范围或分类时，按[解析配图](references/solution-visuals.md)画对区间和关键点，在相应步骤解释怎样读图，辅助线留解析。图和工具结果不能代替证明。

默认A4单栏、宋体12pt、基线18pt，黑体主标题18pt／专题14pt，正文英文数字Times New Roman，公式Cambria Math。左页眉“理学优课高中部”，右“针对补充训练”。标题按实际高中考法命名，短式随文、长式分行对齐，小问各起一行。按[排版规范](references/student-material-standard.md)核对实际PDF的纸型与嵌入字体，替换字体后重新目检。题干和作答区成块，逐页检查公式、字形、分页与空间。模板见[排版模板](assets/preamble.tex)。

## 交付与持续记录

反馈正文、学生训练、学生解析、无提示复测及教师答案按请求交付。明确打包训练、解析和反馈时交老师备课用整包。第一次布置可按学生单独提取训练PDF，家长消息另外转发，学生尝试后另给解析。修改另存新版，同步受影响题答与清单，保留原件和旧版。

分别记材料生成、实际布置、实际提交和完成核对。按题核对关键步骤和最终答案，并记录是否看过提示或解析及独立性依据。部分提交只更新对应题和目标。每次作答保留独立记录，月度按实际作答日期汇总，未知日期留待确认。只收错题时不算整体错误率。

交付前按[逐题验收](references/item-release-review.md)从学生实际看到的 PDF 核完题意、答案、关键步骤和图。再沿目标对齐原题、作答、家长稿、训练与复测判据。未验成品只属候选。教师短核对卡抓目标、证据、关键动作和真实疑点，约五分钟是流程预算，不保证复杂核读也能完成。

## 换Agent使用

分享整个目录，保留相对路径；不依赖原作者聊天、全局技能或其他插件。仅有本入口时也执行以上规则，缺附录不声称已加载。读图、网页和编译能力由宿主提供；缺视觉时接收经核对的转录，缺编译时交可编辑源码并说明状态，见[能力与替代方式](references/runtime-and-capabilities.md)。

在其他设备使用时可转交单技能 ZIP。安装路径和调用提示见[在另一台设备安装](references/install-on-another-device.md)。

可选脚本：`scripts/prepare_evidence.py`准备本地页图，`scripts/math_checks.py`做符号核验，`scripts/compile_pdf.py`编译渲染，`scripts/package_students.py`按[清单](assets/student_bundle.example.json)打包；只在任务需要时使用。不自动安装、配置账号、上传学生资料、创建提醒或向家长发送消息。完整能力范围见[可迁移内容与质量验收](references/portability-and-quality.md)。
