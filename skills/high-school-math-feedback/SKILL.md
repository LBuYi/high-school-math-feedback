# 高中数学错题反馈与针对训练

以真实作答为依据，把“哪里出了问题、下一步怎么练、怎样确认改善”连接起来。用户后续指令优先；沿用已确认的年级、页眉、语气和交付偏好，不重复访谈。

这是一套自包含的工作技能：证据研读、选题、SymPy、数学绘图、LaTeX、PDF 与打包要求均在本目录。常规工作无需先加载其他技能。外部软件、登录会话、编译器仍是运行依赖；已有专门工具可按需使用，遵守当前接口与限制。能力来源、运行检测及可选衔接见 [内部模块与运行环境](references/runtime-and-capabilities.md)。

## 判断本次范围

先检查当前项目 `AGENTS.md`、已有 SOP、执行卡、最新交付清单与本次材料。记录班级、学生、批次、章节和交付范围；不把历史某班人数、章节或日期当作固定配置。

| 请求 | 执行范围 |
| --- | --- |
| 原题＋作答＋批改，要求分析并配训练 | 完整流程；题目依据本批真实内容 |
| 只要反馈或分析 | 核读、独立验题、写反馈；不自动扩成整套练习 |
| 学习教师反馈样本或润色已有反馈 | 读[教师口吻与样本](references/teacher-voice.md)，依据原有事实重写；只更新相关文字与交付 |
| 修订标题、解析或排版 | 读当前有效源稿与 PDF，另存修订版，更新受影响材料和配套答案 |
| 收到复测 | 关联原目标逐步核对，更新证据与状态 |
| 打包学生训练、解析和反馈 | 取最新已核验版本；每人训练 PDF＋学生解析 PDF＋反馈 TXT；不自动混入教师答案或复测 |

缺项先在文件夹、合卷、ZIP 和当前上下文中查找。清楚部分先做；仅对会影响身份、题干或判断的缺项集中询问。教师审核属于教学流程，不意味着每一步制作都要再次征求许可。

## 项目默认标准

- 年级、章节、人数以本批材料为准；考试范围不明确时，以真实错题和已学内容工作，不虚构考试日期。
- 每轮优先 1 个可检验的核心问题，紧密相关时可合并 2 个。题量按覆盖与负荷确定，不固定 10 题，也没有 10 题上限；不靠重复题或拆子问凑数。
- 编排关键步骤、同结构新题、有意义的变式和独立复测；复测通常另配 1—2 题。无明确失分点的学生可安排巩固与迁移，不编造薄弱点。
- 学生用时按实际题量估计，可分次完成；旧访谈的 25—35 分钟不是硬上限。教师每人每轮审核与复测核对合计目标不超过 5 分钟，靠简短核对卡支持。
- 学习反馈采用用户样本中的教师口吻，连贯地讲问题、做法和理由，适度督促，不机械套段落。默认仍直接写给学生；样本使用“他”不自动改变接收人。具体写法见[教师口吻与样本](references/teacher-voice.md)。知识标题采用简洁数学术语；题干和解析用高中数学规范语言。
- 页眉左侧固定 **理学优课高中部**，右侧固定 **针对补充训练**。用户另指定品牌时覆盖。
- 每周一轮，完成并核对复测后再进下一轮。没有新作答时不把“已生成”记成“已掌握”。

## 工作顺序与内部模块

1. **核读与诊断**：读 [材料与反馈](references/materials-and-feedback.md)。保留原件，定位学生原答，先独立验题，再标首次偏离与待验证解释。
2. **选题与适配**：读 [组卷网与训练设计](references/question-research.md)。新增或实质改题时先参考可核读的近期题和典型题；记录真实来源关系，不把搜索摘要当原题。
3. **规范解答与核验**：读 [数学核验与绘图](references/math-and-diagrams.md)。先用学生可用方法写完整解答，再用 SymPy 复核适用部分；按需配 TikZ 或 Matplotlib 图。
4. **分册输出**：读 [PDF 制作与审校](references/pdf-production.md)。统一题库与编号，生成学生训练、学生训练解析、独立复测、教师答案。
5. **复测、版本和打包**：读 [归档与交付](references/retest-and-delivery.md)。更新清单、保留旧版，核对 ZIP 和目标位置后交付；仅按真实提交更新状态。

简单修改或打包只读取需要的模块，不重新检索或重验未变化的全部材料。

## 完整制作的交付

- 可直接复制的反馈正文，并存 UTF-8 TXT。
- 学生训练 PDF：前置知识、分组切入点、规范题干、足够作答空间。
- 学生训练解析 PDF：题号对应，完整规范，不混入复测答案和教师诊断。
- 独立复测 PDF：题面与作答区，不附解题提示。
- 教师答案与核对卡：完整训练和复测解答、证据、疑点及达标步骤；来源明细可另存。

只要求某类交付时按该范围提供。训练解析在独立尝试后提供，复测解析在提交后讲评；不自行向学生或家长发送消息。

## 可执行资源

命令中的 `<skill>` 为本文件所在目录，使用当前可用 Python，不硬编码个人路径。

```text
python <skill>/scripts/inspect_runtime.py
python <skill>/scripts/compile_pdf.py <batch>/latex/main.tex --out-dir <batch>/build-v1 --kind training --student 示例学生
python <skill>/scripts/package_students.py <batch>/student_bundle.json --output <batch>/学生资料.zip
```

- `scripts/math_checks.py`：由本批核验脚本导入，传入审阅后的 SymPy 对象，不执行原文字符串。
- `assets/preamble.tex`：中文数学模板，复制到本批工程后使用；技能目录不存学生产物。
- `assets/student_bundle.example.json`：打包清单结构，路径相对清单目录。
- `assets/batch-record.example.json`：证据、题源、题目和复测记录骨架。

脚本不替代身份判断、一般数学证明或目检；运行报告只记录实际检查。编译成功不等于 PDF 审校通过。
